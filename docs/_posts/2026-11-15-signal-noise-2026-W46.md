## TL;DR
- **Thirteen actively exploited vulnerabilities from CISA's KEV catalog were processed this week.** Six are rated critical. The ones most likely to matter to a small organization are **OpenSSH on Linux (CVE-2026-123158)**, **Barracuda Email Security Gateway (CVE-2026-116606, which can be chained with CVE-2026-111560)**, **Chromium-based browsers (CVE-2026-125350)**, **SonicWall SSL VPN's MFA bypass (CVE-2026-19868)**, **Microsoft Outlook (CVE-2026-124194)** and **Check Point Gaia (CVE-2026-123039)**.
- **CISA set very short deadlines and flagged forensic triage on several of these.** OpenSSH, GPUStack, FreeSWITCH and IBM Aspera Faspex were due 2026-11-12. Both Barracuda CVEs were due 2026-11-13. UnrealIRCd and Check Point were due 2026-11-16. Forensic triage means checking for compromise, not just patching.
- **ClearFake fake-prompt infrastructure grew on each day it appeared.** ThreatFox recorded 109 domains on 11-12, 117 on 11-13 and 174 on 11-15. Many look like hacked legitimate websites.
- **The commodity-malware notes are routine.** They cover Mac stealer AMOS, ACR Stealer, Agent Tesla, Cobalt Strike, AsyncRAT, DCRat and others. All 45 ThreatFox notes are rated medium, and none is linked to a named campaign, actor or ransomware.
- **The data has gaps.** The 60 notes cover only four days (11, 12, 13 and 15 November). More than half (36 of 60) are flagged for analyst review, mostly because their ATT&CK mappings or family descriptions come from public knowledge, not from the source.

## Top threats this week

**1. OpenSSH on Linux: authentication bypass (CVE-2026-123158). Critical. Flagged.**
- **What it is:** OpenSSH is the standard remote-login software on most Linux servers. A bug in how it handles an unexpected return value can let an attacker get past authentication.
- **Who's affected:** OpenSSH before 10.6p2 on Linux. Distributions and appliances that ship OpenSSH may also be affected.
- **Why critical:**
  - It is KEV-listed with active exploitation, and the software is extremely widely deployed.
  - The flaw is reachable over the network and needs no credentials.
  - EPSS puts the chance of exploitation in the next 30 days at 16.5% (97th percentile).
  - CISA's deadline was 2026-11-12 and it requires forensic triage.
- **Caveats:**
  - Attack complexity is high and SSVC rates it not automatable, so some unstated precondition probably limits mass exploitation.
  - The source does not say which configurations or Linux builds are affected. An Alpine advisory URL hints that password authentication is involved, but that is unconfirmed.

**2. Barracuda Email Security Gateway: unauthenticated configuration import (CVE-2026-116606), chainable with root command injection (CVE-2026-111560). Critical.**
- **What it is:**
  - CVE-2026-116606 lets an attacker with no account restore a crafted configuration backup that rewrites the gateway's global configuration.
  - CVE-2026-111560 lets an administrator hide OS commands in a timezone setting, and the appliance runs them as root.
  - CISA says the two can be chained. The 111560 note infers that the chain gives unauthenticated root code execution on ESG. The source does not state this.
- **Who's affected:**
  - ESG before 9.4.0.030 (CVE-2026-116606).
  - Six Barracuda product lines for CVE-2026-111560: ESG, Load Balancer ADC, WAF, Web Security Gateway, Message Archiver and WAF Control Center.
- **Why critical:** both are KEV-listed with active exploitation and affect perimeter appliances. CISA set a three-day deadline (2026-11-13) and requires forensic triage.

**3. Chromium-based browsers: XML use-after-free (CVE-2026-125350). Critical. Flagged.**
- **What it is:** a crafted webpage can run attacker code inside the browser sandbox.
- **Who's affected:** Google Chrome, and per CISA also Microsoft Edge, Opera and other Chromium browsers.
- **Why critical:** it is actively exploited in one of the most widely deployed pieces of software.
- **Caveats:**
  - The victim has to open a page, and the code runs inside the sandbox.
  - The CVE record's version range is malformed. 157.0.8103.50 is probably the fixed Chrome build, but that is inferred.
  - The notes give no fixed versions for Edge or Opera.

**4. SonicWall SonicOS SSL VPN: SAML/MFA bypass (CVE-2026-19868). High.**
- **What it is:** someone with a valid username and password for a different sign-in method on the same appliance can skip SAML, and with it any MFA that SAML enforces. A stolen password alone may get into a VPN that was believed to require MFA.
- **Who's affected:** SonicOS 7.3.3-7015 and older, and 8.2.2-8015 and older.
- **Why high, not critical:** it needs valid credentials, has high attack complexity and is not automatable. It is KEV-listed and CISA's deadline is 2026-11-20.

**5. Microsoft Outlook: missing confirmation allows network spoofing (CVE-2026-124194). High.**
- **What it is:** Outlook can carry out a potentially unsafe action without asking the user first. The source gives no further detail on what is spoofed or how the attack is delivered.
- **Who's affected:**
  - Microsoft 365 Apps for Enterprise (fixed build per Microsoft's release page).
  - Office LTSC 2021 before 16.0.14334.21048.
  - Office LTSC 2024 before 16.0.17932.21140.
- **Why high:** it is actively exploited and Outlook is very widely deployed. It needs user interaction and the technical impact is partial. CISA's deadline is 2026-11-24.

**6. Check Point Gaia OS: local privilege escalation to root (CVE-2026-123039). High.**
- **What it is:** anyone with a low-privilege login on the appliance can have commands run as root through the DynamicCLI service.
- **Who's affected:**
  - Quantum Security Gateway and Quantum Security Management on R82.20 (Jumbo Hotfix Take 10 or below), R82.10 (Take 50 or below), R82 (Take 130 or below) and R81.20 (Take 173 or below).
  - KEV also lists Multi-Domain Security Management and Scalable Platforms, with no separate version data.
- **Why high:** it is actively exploited, but the attacker needs local access first. CISA's deadline was 2026-11-16 and it requires forensic triage.

**7. Other KEV entries: mostly specialized software.**
- **Critical:**
  - **GPUStack (CVE-2026-102895):** unauthenticated admin access and code execution, before 2.2.0.
  - **SignalWire FreeSWITCH (CVE-2026-116779):** unauthenticated command execution on VoIP/PBX servers, before 1.11.3.
- **High:**
  - **IBM Aspera Faspex 5.0.0–5.0.19 (CVE-2026-123218):** CISA's text says an authenticated user is needed, but the vendor's CVSS says no privileges are required.
  - **Cisco BroadWorks (CVE-2026-20320):** unauthenticated read of configuration data. Affected versions are not listed.
  - **UnrealIRCd before 6.2.7.1 (CVE-2026-114713):** linked IRC networks only.
  - **Openwave Webtop Media Transcoder before 1.1.22.0 (CVE-2026-111793)**.

**8. ClearFake drive-by lures. Medium.**
- **What it is:** a malicious script on websites shows visitors a fake prompt, such as a browser update or a "verify you are human" check, that tricks them into installing malware.
- **Volume:** 400 payload-delivery domains across three days. The notes include only 50 per day (150 in total).
- **Why medium:** infection needs a user to act on the prompt, and the source links no campaign or payload. Many listed domains look like hacked small-business sites. Others look attacker-registered: random subdomains on cheap `.store` domains, which ThreatFox rated confidence 100.

**9. Commodity stealers and remote-access tools. Medium.**
- **Stealers:**
  - **AMOS** (Mac stealer): 11 + 11 + 8 indicators.
  - **ACR Stealer:** 10 + 19 + 6 + 2 indicators.
  - **Agent Tesla:** 1 + 19 + 1 hashes.
- **Remote-access trojans (RATs) and command-and-control (C2) servers:**
  - Cobalt Strike: 18 + 14 + 14 indicators.
  - AsyncRAT: 12 + 10 + 8 indicators.
  - DCRat, AdaptixC2, CrossRAT, DanaBot, Amadey and others.
- **ContagiousDrop:** two Vercel-hosted delivery domains. Their reference is titled as describing malicious VS Code `tasks.json` abuse.
- **No ransomware link:** none is tied by the source to ransomware or a named actor.
- **Why it still matters:** any internal host contacting these C2 servers should be treated as likely compromised.

## What changed vs. prior weeks
- **ClearFake is the only comparison the notes allow.** The 174 domains on 2026-11-15 are about double the 82 seen in an earlier ClearFake day-cluster, and volume rose on each day it appeared this week (109 → 117 → 174).
- **CECbot C2 servers grew within the week:** 1 → 2 → 6. All use port 10213, and most sit in 31.57.x.x.
- **Everything else is still a baseline.** The notes do not support any other week-over-week comparison.

## What a small organization should actually do

**Patch first, in this order:**
1. **OpenSSH (CVE-2026-123158).**
   - Find every Linux server and appliance running OpenSSH.
   - Update to 10.6p2 or later, or your distribution's patched package. The notes infer 10.6p2 from the affected range "before 10.6p2", so confirm it with your vendor.
   - Until patched, limit SSH access to known IP addresses or a VPN.
   - CISA flagged this for forensic triage, so review SSH login logs on exposed servers for successful logins you can't explain.
2. **Barracuda ESG and other Barracuda appliances (CVE-2026-116606, CVE-2026-111560).**
   - If you run ESG, make sure it is at 9.4.0.030 or later.
   - For WAF, Load Balancer ADC, Web Security Gateway, Message Archiver and WAF Control Center, follow Barracuda's advisory, because the notes name no fixed versions: https://trust.barracuda.com/security/pre-authentication-authorization-bypass-command-injection
   - CISA requires forensic triage. Check the ESG's global configuration and timezone setting for changes you did not make.
3. **Browsers (CVE-2026-125350).**
   - Update Chrome to at least 157.0.8103.50. This build is inferred from the CVE record, so confirm it against the Chrome release note.
   - Push current updates to Edge and Opera. The notes have no fixed version for them.
4. **SonicWall SSL VPN (CVE-2026-19868).**
   - Upgrade beyond 7.3.3-7015 / 8.2.2-8015 following SonicWall's advisory: https://psirt.global.sonicwall.com/vuln-detail/SNWLID-2026-0014
   - Until then, the bypass depends on valid credentials for a non-SAML sign-in method. Disable those methods on the SSL VPN where you can, or reset their passwords.
   - Review VPN logins that did not go through SAML.
5. **Outlook (CVE-2026-124194).** Bring Office LTSC 2021 to 16.0.14334.21048 or later, LTSC 2024 to 16.0.17932.21140 or later, and Microsoft 365 Apps to the build Microsoft lists at https://aka.ms/OfficeSecurityReleases
6. **Check Point Gaia (CVE-2026-123039).**
   - Install a Jumbo Hotfix Take above the vulnerable ones listed for your release (sk1000362).
   - Exploitation needs a low-privilege login on the appliance, so review which local accounts exist and remove any you don't need.
   - Look for signs of compromise, as CISA requires forensic triage.
7. **Only if you run them:**
   - GPUStack: update to 2.2.0 or later, then rotate the admin API keys and cloud credentials it stores.
   - FreeSWITCH: update to 1.11.3 or later, and rotate stored credentials.
   - IBM Aspera Faspex: update past 5.0.19.
   - UnrealIRCd: update to 6.2.7.1 or later.
   - Openwave Webtop Media Transcoder: update to 1.1.22.0 or later.
   - Cisco BroadWorks: follow Cisco's advisory.

**Block and hunt (DNS filter, web proxy, firewall logs):**
- **ACR Stealer C2 domains:** for example `wrenmereton.cc`, `hollowick.cc`, `mainenteew.top`, `debug.sablecroft.cc` and `ml.mirthvaleway.cc`. Use the full lists in the 11-11, 11-12 and 11-15 notes.
- **AMOS (Mac) delivery and C2:** `quartz-pearl.com`, `nimbus-90.com`, `wire-pixel.com`, `feedweave14.com`, `seohumanoid.com`, `raster15.com`, `coral-stratos.com` and `mostbeat12.com`. If you have Macs, also search them for the AMOS hashes in the notes.
- **ContagiousDrop:** block the exact hostnames `tarsai-red.vercel.app` and `api-check-one.vercel.app`, not all of `vercel.app`.
- **ClearFake:**
  - Block the attacker-registered domains, such as `gorti.store`, `galsab.store`, `devam.store`, `gamev.store`, `udap.store` and their random subdomains.
  - Be careful with the hacked legitimate sites in the lists. Blocking them also blocks real businesses.
- **C2 servers:**
  - Search firewall logs for the Cobalt Strike, AsyncRAT, DCRat, AdaptixC2, DanaBot and CECbot IP:port pairs in the notes.
  - Treat any internal hit as a compromised host and investigate it.
  - Block by IP:port, not whole IPs, where the notes say the IP may be shared hosting.
- **Payload hashes:** load the hashes (Agent Tesla, ACR Stealer, CrossRAT, ClipBanker, Coinminer, Babadeda, Bashlite) into your endpoint tool. Some are detected by fewer than a quarter of VirusTotal engines, so don't rely on antivirus alone.
- **SmartApeSG/ClickFix:** the note has no indicators, so there is nothing to block from this week's data.
