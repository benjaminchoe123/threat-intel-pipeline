## Top threats this week

### 1. CVE-2026-102764: BeyondTrust Remote Support authentication bypass (critical)

- **What it is:** BeyondTrust Remote Support is a remote-access appliance that IT and help-desk teams use to connect to and control other computers. Because of this flaw, a remote attacker can get past its login checks by spoofing and then perform file operations on the appliance. The source does not say whether "file operations" means reading files, writing them, or both. It also does not say whether the flaw can lead to code execution.
- **Who's affected:** Any organization running BeyondTrust Remote Support. The affected versions are not stated in the source. See vendor advisory BT26-05.
- **Severity: critical, because:**
  - CISA lists it in KEV, which confirms active exploitation.
  - No credentials are needed. It is an authentication bypass (CWE-290) that a remote attacker can use.
  - It is a privileged remote-access tool, so a compromised appliance gives an attacker a strong foothold for reaching the systems it manages.
  - CISA gave only three days to fix it and requires forensic triage.
- **Caveats:** The note's confidence is **medium**. The critical rating rests on unauthenticated access, not on confirmed code execution. It also relies partly on general knowledge that the product is widely deployed, which the source data does not state. The EPSS score is low (0.6%), but confirmed KEV exploitation overrides it. Ransomware use is listed as "Unknown."

### 2. CVE-2025-61624: Fortinet path traversal allowing arbitrary file write/delete (high)

- **What it is:** This is a path traversal flaw (CWE-22) in several Fortinet products. An attacker who is already logged in with an admin profile that has at least read-write permissions can use specific CLI commands to write or delete files anywhere on the device, not only the files that account is supposed to manage.
- **Who's affected:** Organizations running Fortinet FortiOS, FortiPAM, FortiProxy or FortiSwitchManager. The affected and fixed versions are not stated in the source. See vendor advisory FG-IR-26-122.
- **Severity: high, because:**
  - The KEV listing confirms active exploitation, which sets the floor at high.
  - It is not rated critical because the attacker must already hold read-write admin credentials, and the flaw is not unauthenticated remote code execution.
  - Urgency within the high band is raised by three things: these are perimeter and infrastructure devices, an arbitrary file write or delete could undermine the device's integrity or availability, and CISA set a three-day deadline with forensic triage.
- **Caveats:** The note's confidence is **high**. The source does not say how attackers got admin credentials in the attacks seen so far, what files they wrote or deleted, or what they did afterward. The EPSS score is low (0.58%), but confirmed KEV exploitation overrides it. Ransomware use is listed as "Unknown."

## What a small organization should actually do

1. **Check today whether you run BeyondTrust Remote Support or any of the four Fortinet products.** Everything below applies only if you do. If you run neither, no action from this week's notes is needed.
2. **BeyondTrust Remote Support: patch first.** This is the higher-severity item and needs no credentials to exploit. Apply the fix described in vendor advisory BT26-05 before CISA's 2026-10-19 deadline. The notes do not list the fixed versions, so take them from the advisory.
3. **BeyondTrust: check for compromise as well as patching.** CISA requires forensic triage, so a patch alone does not show that the appliance was not used before you fixed it. Review the appliance for file changes and sessions you cannot explain. If you have a managed IT or security provider, ask them to do this review. The notes contain no IOCs, so there is nothing specific to search for.
4. **BeyondTrust: until the patch is in, limit which networks and addresses can reach the appliance, as far as your support workflow allows.** The attack comes from a remote attacker over the network, so fewer reachable sources means less exposure.
5. **Fortinet: patch FortiOS, FortiPAM, FortiProxy and FortiSwitchManager** using vendor advisory FG-IR-26-122, before the 2026-10-19 deadline.
6. **Fortinet: reduce who can exploit the flaw.** It requires an admin account with read-write permissions, so:
   - List every admin account that has a read-write profile.
   - Remove accounts that are not needed, or downgrade them.
   - Change the passwords on the accounts you keep.
   - Restrict management and CLI access to trusted internal addresses only.
7. **Fortinet: run the forensic triage CISA requires.** Review admin login history for logins you cannot explain, and check the devices for unexpected file changes or deletions.
