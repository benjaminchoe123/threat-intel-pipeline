# Weekly Threat Report — 2026-W30

## TL;DR

- Six critical vulnerabilities are currently active in CISA's Known Exploited Vulnerabilities (KEV) catalog. Four (SharePoint's two CVEs, FortiSandbox's two CVEs) were confirmed added 07-14 to 07-16; Oracle E-Business Suite has a 07-18 remediation due date with no stated add date; Balbooa Forms and a legacy Cisco IOS 12.4 flaw (below) were both added just before this reporting period (07-10 and 07-13). All are already being actively attacked, and most require no login at all. If you run **Microsoft SharePoint Server, Oracle E-Business Suite, Fortinet FortiSandbox, or Joomla with the Balbooa Forms extension**, patch now.
- A very old vulnerability (from 2008) in **Cisco IOS 12.4** was added to KEV just before this reporting period (07-13) — a reminder to check for end-of-life network gear still running in production.
- Attacker "command and control" infrastructure for post-exploitation tools (**Cobalt Strike, AdaptixC2, Havoc**) was active throughout the week — Cobalt Strike's IOC volume climbed sharply (6 → 36), while AdaptixC2 spiked then dropped (7 → 50 → 19). Cobalt Strike and part of the AdaptixC2 activity carry a ransomware-precursor association in the source data; Havoc and the later AdaptixC2 cluster do not — but all of it is traffic worth blocking on sight, not routine malware.
- Fake "update your browser" malware campaigns remained large-scale all week for **ClearFake**, including a single-day cluster of 206 malicious domains; **SocGholish/FAKEUPDATES** appeared in a smaller, single cluster this week — these spread through ordinary, otherwise-legitimate compromised websites, not just sketchy ones.
- Commodity credential-stealing malware (Agent Tesla, Formbook, AsyncRAT, and others) continued at routine, steady volume — no single family stood out, but the aggregate volume means email and endpoint defenses need to stay current.

## Top threats this week

**1. Microsoft SharePoint Server — two separate actively-exploited flaws (CVE-2026-56164, CVE-2026-58644)**
What it is: Attackers with no login credentials can take over a SharePoint server directly over the network. Who's affected: any organization running on-premises SharePoint Server exposed to the internet or an internal network attackers can reach. Severity: **Critical** — both are KEV-listed, unauthenticated, and SharePoint is extremely widely deployed. Both carried a 3-day federal remediation deadline (CVE-2026-56164: added 07-14, due 07-17; CVE-2026-58644: added 07-16, due 07-19).

**2. Oracle E-Business Suite — Oracle Payments takeover (CVE-2026-46817)**
What it is: An attacker with only network/HTTP access, no login, can take over the Payments module of this widely used ERP system, exposing financial data and workflows. Who's affected: organizations running Oracle E-Business Suite. Severity: **Critical** — actively exploited, unauthenticated, hits financial processing directly.

**3. Fortinet FortiSandbox — two actively-exploited command-injection flaws (CVE-2026-39808, CVE-2026-25089)**
What it is: An attacker with no login can send a crafted web request and run arbitrary system commands on the appliance your organization may use to detonate suspicious files. Who's affected: anyone running FortiSandbox, FortiSandbox Cloud, or FortiSandbox PaaS. Severity: **Critical** — unauthenticated RCE, actively exploited, and one scores in the 99.6th percentile for predicted near-term exploitation.

**4. Balbooa Forms (Joomla extension) — unauthenticated file upload (CVE-2026-56291)**
What it is: Anyone on the internet can upload and run malicious files on an affected Joomla site with this form-builder extension installed, no login required. Severity: **Critical** — full server takeover, actively exploited, unusually short 3-day remediation window from CISA.

**5. Cobalt Strike, AdaptixC2, and Havoc C2 infrastructure — active throughout the week**
What it is: These are "post-exploitation" frameworks that give an attacker remote control of a compromised machine — legitimate security tools that are also the standard toolkit used between initial compromise and ransomware deployment. Who's affected: any organization with a compromised endpoint that phones home to this infrastructure. Severity: **High for Cobalt Strike and the 07-15 AdaptixC2 cluster** (both carry a stated ransomware association — treat as a likely ransomware precursor) — **also High, but on volume alone, for the 07-17 AdaptixC2 cluster** (no ransomware association established in the source) — **Medium for the most recent AdaptixC2 cluster** (07-20, 19 IOCs), which the source data rates lower still.

**6. SonicWall SMA1000 remote-access appliances — two actively-exploited flaws (CVE-2026-15409, CVE-2026-15410)**
What it is: An SSRF flaw exploitable without login, plus a code-injection flaw exploitable by an already-authenticated admin, both on internet-facing remote-access gateways. Who's affected: organizations using SonicWall SMA1000 for remote employee access. Severity: **High** — KEV-listed, edge infrastructure that's internet-facing by design.

**7. SocGholish/FAKEUPDATES and ClearFake fake-update campaigns**
What it is: Malicious JavaScript injected into otherwise-legitimate, compromised websites shows visitors a fake "update your browser" prompt that tricks them into installing malware. Who's affected: any employee browsing the web — infection doesn't require visiting a suspicious site, just an already-compromised legitimate one. Severity: **High** — large, active, ongoing campaigns (one single-day cluster included 206 new malicious domains); SocGholish specifically has a history of leading to ransomware deployment.

**8. Cisco IOS 12.4 — CSRF leading to command execution (CVE-2008-4128)**
What it is: An 18-year-old vulnerability, newly confirmed under active exploitation, in the web management interface of old Cisco routers/switches. A logged-in administrator's browser can be tricked into sending crafted requests to specific device URIs (a CSRF flaw), resulting in arbitrary commands run on the device. Severity: **High** — requires an authenticated admin session and the device's HTTP interface enabled; the affected IOS 12.4 line is long past end-of-life/obsolete per Cisco, so check whether a patch is available for your specific device rather than assuming one exists.

## What changed vs prior weeks

This is the first report generated from this pipeline's daily notes, so a multi-week baseline isn't yet established. Within this week itself: Cobalt Strike's daily ThreatFox clusters grew notably day over day (6 → 36 IOCs), suggesting active, ongoing infrastructure buildout. AdaptixC2 instead spiked then dropped (7 → 50 → 19 IOCs) — worth watching, but not yet a sustained growth trend. Future weekly reports will be able to compare against this baseline.

## What a small organization should actually do

1. **Patch immediately if you run any of these**: Microsoft SharePoint Server, Oracle E-Business Suite, Fortinet FortiSandbox (any edition), SonicWall SMA1000, or Joomla with the Balbooa Forms extension. All are KEV-listed with short remediation windows because they're under active attack right now.
2. **Inventory your network gear for end-of-life Cisco IOS 12.4 devices.** If found, restrict or disable access to the device's web management interface, and check with Cisco whether a patch exists for your specific hardware rather than assuming one does.
3. **Block outbound traffic to the C2 indicators listed in this week's AdaptixC2, Cobalt Strike, and Havoc notes** (see the vault threat notes for full IP:port lists) at your firewall/proxy, and treat any internal host that tries to reach one as a likely active compromise requiring immediate investigation — not routine malware cleanup.
4. **Remind staff that "update your browser" prompts encountered while browsing should never be trusted**, even on familiar, legitimate-looking sites — this is the SocGholish/ClearFake delivery method, and it doesn't require visiting a suspicious site to succeed.
5. **Keep email attachment scanning and endpoint AV signatures current.** Commodity stealers (Agent Tesla, Formbook, AsyncRAT, DCRat, and others) circulated in routine but steady volume all week; standard hygiene remains the effective control here, no special action needed beyond staying current.
