# Weekly Threat Report — 2026-W35

## TL;DR

- Nine CISA Known Exploited Vulnerabilities (KEV) entries are covered here, seven of them rated critical. Their CISA catalogue dates run 2026-08-18 to 2026-08-24 and the pipeline ingested them between 2026-08-23 and 2026-08-25, so this edition straddles the end of ISO week 34 and the start of week 35 rather than mapping cleanly onto either. All are confirmed exploited in the wild, not theoretical.
- Six of those KEV entries carried three-day federal remediation deadlines that have **already passed** as of 2026-08-25: Windows IKE (CVE-2026-33824), SharePoint (CVE-2026-55040), VMware vCenter (CVE-2026-59310), macOS Screen Sharing (CVE-2026-65400), Zimbra (CVE-2026-73570), and TrueConf (CVE-2026-72529). If you run any of these unpatched, you are past due.
- The highest-volume activity was browser-delivered malware: 121 ClearFake indicators in a single day, plus a fresh FAKEUPDATES C2 domain and a SmartApeSG "ClickFix" campaign. None of the three needs a software vulnerability. FAKEUPDATES depends on the user running a downloaded fake update and SmartApeSG on the user pasting a command; the ClearFake source describes no page content or interaction step, so no specific user action can be asserted for it.
- 27 Cobalt Strike C2 endpoints across 12 hosts appeared in a 24-hour window. Cobalt Strike is commonly the hands-on-keyboard stage before ransomware.
- Data caveats worth stating plainly: the ClearFake note lists only 50 of 121 indicators, the SmartApeSG note was built from a headline with no indicators, and several single-indicator C2 reports (DarkComet, DCRat) have no independent corroboration.

## Top threats this week

**1. Fake update and "ClickFix" lures — ClearFake, FAKEUPDATES, SmartApeSG (high / high / medium)**

What it is: web pages that tell a visitor their browser is out of date, a video needs a codec, or a CAPTCHA is broken — then hand them a file to run or a command to copy and paste. ClearFake alone produced 121 indicators on 2026-08-25, arriving in bursts roughly every ten minutes across a ten-hour window. Many of the delivery domains are ordinary business sites (law firms, dental clinics, contractors, a WP Engine staging host) that appear to have been compromised and repurposed, so web-category filtering and reputation scoring will under-block them. One indicator stages content on the public jsDelivr CDN, which blends with normal developer traffic.

Who's affected: end-user web browsers. The ClearFake and FAKEUPDATES notes name no platform. The SmartApeSG note adds, as general background on ClickFix chains, that they generally target Windows desktop users. No vulnerable software is needed.

Severity and why: high for ClearFake (volume and scale of an active campaign, plus a command-and-control indicator showing that control follows successful delivery) and high for FAKEUPDATES (that family's infections have repeatedly been handed off to ransomware operators). SmartApeSG is rated medium only because the source was a headline with no volume or scale data — and because delivery depends on the user pasting the command themselves.

**2. Microsoft IKE Service Extensions remote code execution — CVE-2026-33824 (critical)**

What it is: a memory-corruption flaw in the Windows service that negotiates IPsec VPN tunnels. It allows remote code execution, and the affected component typically sits at the network edge on anything terminating VPN or IPsec connections.

Who's affected: organizations running Windows IPsec/VPN endpoints.

Severity and why: critical. Actively exploited, remote code execution, widely deployed Microsoft software at the perimeter. Its EPSS score of 72.7% (99.4th percentile) is the highest of any item this week. CISA's due date of 2026-08-21 has passed.

**3. Apple macOS Screen Sharing authentication bypass — CVE-2026-65400 (critical)**

What it is: an attacker who can reach a Mac over the network can connect to Screen Sharing without any username or password, giving them interactive control of the desktop.

Who's affected: any macOS fleet. Apple published three advisories (support.apple.com articles 148170, 148171, 148172), consistent with fixes across multiple macOS releases; the KEV entry does not name affected versions, so treat all builds as affected until confirmed patched.

Severity and why: critical. Unauthenticated, no user interaction, and the outcome is equivalent to someone sitting at the keyboard. Due date 2026-08-21 has passed.

**4. Microsoft SharePoint weak authentication — CVE-2026-55040 (critical)**

What it is: an attacker with no valid credentials can bypass a security control over the network and reach protected SharePoint functionality.

Who's affected: SharePoint deployments, on-premises and — per CISA's required action referencing BOD 26-04 cloud guidance — hosted/cloud instances too.

Severity and why: critical. Confirmed exploitation, no authentication precondition, and SharePoint typically holds sensitive business documents. The specific security feature bypassed and the post-bypass impact are not stated in the source. Due date 2026-08-21 has passed.

**5. VMware vCenter path traversal to remote code execution — CVE-2026-59310 (critical)**

What it is: an attacker with network access to vCenter can execute arbitrary code on it. vCenter is the control plane for a VMware estate — whoever controls it can generally reach, clone, or destroy every VM it manages.

Who's affected: anyone running VMware vCenter.

Severity and why: critical. Confirmed exploitation, EPSS 45.9% (98.7th percentile), and the blast radius extends to every hypervisor and guest underneath. Due date 2026-08-21 has passed.

**6. Zimbra Collaboration Suite OS command injection — CVE-2026-73570 (critical)**

What it is: an attacker with no account sends a crafted SMTP request and the mail server runs operating-system commands as the `zimbra` user. The only precondition is being able to send mail to the server, which is what a mail server is for.

Who's affected: the note describes Zimbra as core mail infrastructure across enterprises, government, and hosting providers. The KEV entry does not enumerate versions; the vendor references point to a Zimbra 10.1.20 patch release.

Severity and why: critical. Unauthenticated remote code execution in internet-facing mail infrastructure, with direct access to mailbox data. Due date 2026-08-24 has passed.

**7. Oracle HTTP Server / WebLogic Proxy Plug-in access control flaw — CVE-2026-21962 (critical)**

What it is: an improper access control flaw letting an attacker who reaches the component read, create, modify, or delete data the product can access. These components typically front enterprise web applications.

Who's affected: Oracle middleware stacks. Version ranges are not in the source; consult the Oracle Critical Patch Update for January 2026.

Severity and why: critical, with EPSS at 42.0% (98.5th percentile). The remediation deadline is **2026-08-27 — two days out**, the nearest of the three KEV deadlines this week still open (the other two: MLflow CVE-2026-64849 on 2026-09-02 and TrueConf CVE-2026-72530 on 2026-09-03). Note the analyst caveat: the source does not state whether exploitation requires authentication, and if it does, high would be the better rating.

**8. Cobalt Strike command-and-control surge (high)**

What it is: 27 C2 listeners across 12 IP addresses, all first seen inside a 24-hour window, 24 of them at maximum reporting confidence. Cobalt Strike Beacon is the tool attackers use after they are already inside — running commands, stealing credentials, moving laterally — and it frequently precedes ransomware deployment.

Who's affected: this only matters if something already has a foothold, but that is exactly why it matters — a hit on one of these addresses is an incident, not an alert.

Severity and why: high. Ransomware-stage tooling plus the volume and freshness of the infrastructure. Three of the indicators carry lower (75%) reporting confidence, and three sit on port 22, which may just be an SSH management service on the same host rather than a real listener.

**9. TrueConf Server — two flaws, CVE-2026-72529 (critical) and CVE-2026-72530 (high)**

What it is: a self-hosted video conferencing product with a service on TCP port 4307 that performs a sensitive function without checking who is calling. CVE-2026-72529 lets an unauthenticated attacker make the server run a script of their choosing; CVE-2026-72530 lets an attacker escape the script sandbox onto the host operating system. Neither requires a login.

Who's affected: organizations self-hosting TrueConf Server. Fixed versions are not stated in the KEV entries; see the vendor advisory page.

Severity and why: critical and high respectively. Both are actively exploited unauthenticated code execution, but TrueConf is a niche product on a non-standard port, which limits how many organizations are exposed. The 72529 deadline (2026-08-23) has passed; 72530 is due 2026-09-03.

**10. MLflow server-side request forgery — CVE-2026-64849 (high)**

What it is: an attacker who can reach an MLflow server makes it send requests on their behalf to internal-only systems, including the cloud metadata service that hands out an instance's credentials — and the full response body comes back. That turns into usable cloud credentials.

Who's affected: teams running MLflow for machine-learning experiment tracking. The note characterises it as significant but specialized MLOps software; it says nothing about how widely small organizations deploy it.

Severity and why: high, not critical — it is not remote code execution and not wormable, and MLflow is specialized software. Due 2026-09-02. EPSS 16.4%.

**11. Commodity remote access trojan and botnet C2 (medium)**

AsyncRAT (3 indicators), Aisuru IoT botnet (4 indicators), DCRat (1), and DarkComet (1). These are routine daily indicator clusters, not campaigns. Each represents attacker infrastructure worth blocking, but the volume is low and third-party corroboration is thin — the DarkComet indicator has zero malicious VirusTotal verdicts and zero AbuseIPDB reports and is flagged low confidence. Aisuru targets internet-exposed IoT devices such as routers, DVRs, and cameras.

## What changed vs. prior weeks

The notes for this week contain no prior-week data, so the activity baseline is still being established — nothing here supports a claim that volume is up, down, or unusual compared to any earlier period.

Two observations are supported within the week's own data. First, seven of the nine KEV additions were rated critical, and four of them (CVE-2026-33824, CVE-2026-55040, CVE-2026-59310, CVE-2026-65400) were all added on 2026-08-18 with a common 2026-08-21 due date. Second, several notes record that these three-day windows are far shorter than the standard BOD 26-04 timeline of roughly three weeks, which is CISA signalling urgency. Whether that clustering is unusual cannot be determined from this week's notes alone.

## What a small organization should actually do

**This week, in this order:**

1. **Patch anything on this list that you run — the deadline has already passed on most of them.** Windows systems terminating VPN/IPsec (CVE-2026-33824), all Macs (CVE-2026-65400 — check Apple advisories 148170/148171/148172), SharePoint on-prem or hosted (CVE-2026-55040), VMware vCenter (CVE-2026-59310), Zimbra (CVE-2026-73570 — vendor references point to 10.1.20), TrueConf Server (CVE-2026-72529 and -72530).
2. **If you run Oracle HTTP Server or the WebLogic Proxy Plug-in, patch before 2026-08-27** using the Oracle Critical Patch Update for January 2026. This is the nearest deadline still ahead of you.
3. **Do not let CVE-2026-65400 slip because it is the only Apple item on the list.** On an unpatched Mac it is an unauthenticated path to full interactive desktop control — the note rates it critical with no user interaction required, and its 2026-08-21 deadline has already passed.
4. **Use internet exposure to prioritise, where the sources actually say to.** CISA's required action for MLflow explicitly tells asset owners to scope by internet exposure, and the TrueConf note singles out TCP port 4307 as the reachable service. The SharePoint entry points at BOD 26-04 cloud guidance instead. Note that the SharePoint note calls it a commonly internet-facing web application, and Zimbra is reachable by design — a mail server receiving SMTP is doing its job — so for those two the answer is patching, not exposure reduction. The vCenter note says only that the attacker needs network access to vCenter; it makes no claim about how exposed vCenter typically is.
5. **Block the C2 addresses and hunt your outbound logs for them.** The Cobalt Strike set is the priority. Its note draws two distinctions: three of the indicators carry 75% reporter confidence and are graded lower-grade than the rest, and eight of the twelve IPs were never checked against VirusTotal or AbuseIPDB at all. The note does not say which four were checked, so whether those two groups overlap cannot be determined from the source. Absent reputation data is expected for freshly stood-up C2 and is not evidence that an address is benign; unchecked is not the same as clean, and neither is the same as low-confidence. Block all twelve. The 12 IPs: 38.147.185.54, 177.3.89.54, 182.92.78.7, 43.143.13.146, 149.88.66.234, 121.4.38.18, 118.24.172.48, 47.96.123.205, 91.92.240.88, 64.83.24.34, 207.57.123.57, 175.27.214.144. Then AsyncRAT (80.190.77.86:30700, 50.116.42.10:8808), Aisuru (46.101.146.87:8080, 159.89.24.55:9035, 168.144.188.31:8080, 64.227.187.82:34567), DCRat (69.167.11.198:7777), DarkComet (132.243.172.182:1604), and the FAKEUPDATES domain `prime.destroythebrainonline.com`. **An internal host connecting to a Cobalt Strike or AsyncRAT address is an incident — isolate the machine, don't just clear the alert.** Two carry less weight than that: the DCRat indicator sits at 75% reporter confidence with 2/52 VirusTotal support and may be shared hosting, so its note puts it at "suggests compromise" and says to verify against egress logs first; and the DarkComet indicator is rated low confidence with clean VirusTotal and AbuseIPDB results, so treat a hit there as something to investigate rather than a confirmed compromise.
6. **Two indicators need care before you block them:** AsyncRAT's 160.25.140.133:443 carries only 50% reporter confidence, and the underlying note rates port 443 on a shared host as far more likely to be legitimate than that campaign's two high-port indicators — a comparison between the three, not a verdict that the address is benign. The DCRat IP may be shared hosting. Check these against your own egress logs first.
7. **Build the ClearFake blocklist from the full ThreatFox export for 2026-08-25, not from this report.** Only 50 of 121 indicators are listed in the underlying note. Note that many of the delivery domains are legitimate compromised business sites, so blocking them may affect real destinations — and conversely, reputation filtering will not catch them for you.
8. **Tell staff one specific thing, not a general reminder:** the SmartApeSG chain works by getting the user to copy an attacker-supplied command and run it themselves, and the FAKEUPDATES chain by getting the user to run a downloaded fake update. Those two user actions are the whole delivery mechanism for those campaigns, which is what makes them worth naming to staff specifically. Those are two separate instructions and both are needed: the copy-and-paste half covers SmartApeSG, whose note maps T1204.004 (ClickFix), and the never-trust-an-update-prompt half covers FAKEUPDATES, whose note maps T1204.002 — the user running a downloaded file. Give them for ClearFake as well, though its source describes no page content or user-interaction step, so neither action can be asserted for that campaign.
9. **If you have routers, DVRs, or cameras reachable from the internet, take them off the public internet.** That is the device class the Aisuru botnet recruits. The source names no specific models or firmware versions, so removing the exposure is the action actually available here — there is nothing in this week's data to point a targeted patch at.

**Lower priority:** patch MLflow before 2026-09-02 if you run it. It is specialized MLOps software, so many readers will have nothing to do here.
